On the machine

Studios in one local document tree

Part studios, assemblies, drawings, CAM, simulation, render, and PCB sit in the same project. Check-in writes a SQLite revision, not a cloud commit.

Runtime binding is on the specs page. Installers are on download. How to patch: contribute.

PDM

Local-first versioning

Every check-in is a row in SQLite. WAL on disk, checkout on the feature tree, release states without an account. Path: .cad_workspace/*.cad_db

ECAD

Board in the same tree

Snap routing, DRC profiles, Gerber and Excellon out. The board is not a second vendor login. It sits next to the solid that will mill it.

Assembly

Snap, then mate

Concentric and coincident snaps lock before the dialog stack appears. Instances stay in a local BOM on this machine.

Sculpt

T-spline cage

Control mesh and subdivided surface in the same studio as BREP extrudes. Organic bodies are not a separate clay app with a second license.

CAM

Stock, WCS, pocket

2.5D zigzag clear and a Fanuc-style post. Verify on the controller. Arbor does not claim 5-axis or certified toolpaths.

Sim / Render

UI scaffolds

Simulation and render studios exist as desktop UI scaffolds. They are listed here so the map is honest, not so a brochure can invent solvers.

The home page shows a compressed map of four of these systems. This page is the fuller list. Nothing here is a fake customer count. If a studio is still a scaffold, it is named as one.
